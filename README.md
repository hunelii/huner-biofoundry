# Huner Biofoundry — reconstructed stable checkpoint

See [checkpoint provenance](docs/CHECKPOINT.md). This local reconstruction is based on the approved pre-Higgsfield design described in the conversation, not an exact recovery of the deployed source. The public Vercel website is unchanged.

## Local development

Use Node 24, then `npm ci` and `npm run dev`. `npm run build` creates the static export in `out/`. `npm test` runs model and launch checks.

The retained homepage includes the semantic arrival, delayed environment → biological growth simulation, Conditions with uninterrupted growth behind text, the original schematic 3D fungal cell, applications, milestones and team. No photographs or ivy are integrated.

`/?lab=1` exposes the existing simulation checks in development. `/?gpu=off` exercises the static fallback; reduced motion selects the same fallback. Amazing Grotesk remains the intended family with the existing Helvetica Neue/Arial fallback until a licensed font file is supplied.

`checkpoint/pre-higgsfield-final` and `production/stable` are frozen after verification. New visual work belongs on `experiment/organic-world`, starting from that tag, at the isolated `/lab/organic-world` route. Do not modify the homepage or publish experimental work without explicit integration approval.
